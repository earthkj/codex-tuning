# Codex Tuning

Codex를 실제 개발에 사용하면서 공통 지침을 다듬고, 사용량을 확인하는 개인 작업 설정입니다. 프로젝트별 요구사항과 실행 명령은 각 프로젝트의 `AGENTS.md`에서 관리합니다.

## 구성

- `AGENTS.md`: 언어, 변경 범위, 탐색, 검증에 대한 공통 지침
- `USAGE.md`: 사용량 조회와 답변 표시 규칙
- `usage_snapshot.py`: 현재 채팅의 기록된 입력 토큰 조회
- `test_usage_snapshot.py`: 조회 범위와 로그 처리 테스트

## 개선한 내용

- 공통 지침에는 짧고 안정적인 규칙을 남기고, 상세 사용량 규칙을 별도 파일로 분리했습니다.
- 고정된 PC 경로 대신 `CODEX_HOME` 또는 사용자 홈의 `.codex`를 사용합니다.
- 불필요한 반복 탐색과 검증을 줄이되, 변경·실패·미해결 문제가 있을 때는 다시 확인하도록 명시했습니다.
- 사용량은 추정하지 않고 기록된 값만 표시하며, 현재 채팅의 이번 턴 기록을 우선합니다.

지침을 통해 의도한 동작을 정리한 것으로, 토큰 절감률이나 생산성 향상률을 측정한 결과는 아닙니다.

## 적용

`AGENTS.md`, `USAGE.md`, `usage_snapshot.py`를 Codex 설정 디렉터리에 함께 배치합니다. `CODEX_HOME`이 설정되어 있으면 해당 디렉터리, 없으면 사용자 홈의 `.codex`입니다. 기존 설정이 있다면 필요한 부분만 병합하세요.

사용량 표시는 선택 사항입니다. 사용하지 않으려면 `AGENTS.md`의 사용량 표시 항목을 제거하면 됩니다.

## 검증과 한계

```shell
python -m unittest test_usage_snapshot.py
```

스크립트는 `CODEX_THREAD_ID`로 현재 채팅을 찾고, 로컬 `state_5.sqlite`를 읽기 전용으로 조회하여 해당 로그의 끝부분만 읽습니다. 로그·DB·인증 정보는 저장소에 포함하지 않습니다.

Codex 내부 DB 구조와 기록 형식에 의존하므로 환경이나 버전에 따라 동작하지 않을 수 있습니다. 최종 답변 생성분은 조회에 포함되지 않으며, 현재 턴 기록이 없으면 최근 요청 기록임을 구분하거나 조회 불가를 반환합니다. 계정 잔여 한도는 스크립트가 아닌 Codex에서 제공하는 사용량 한도 도구로 확인합니다.
